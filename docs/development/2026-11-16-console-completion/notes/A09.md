## Windows failure and smallest repair

Fetched the log for [job 133764382636](https://github.com/tomasedisonn80/Hammond-B3-Organ/actions/runs/44000895418/job/133764382636).
Step 11, **Build the application and every standalone acceptance input**, fails
in `apps/standalone/native_tests/test_standalone_header_material.cpp:156`.
MSVC reports two C4244 `int` to `float` conversion warnings at columns 34 and
71, then C2220 because `/WX` correctly treats those warnings as errors.
Native acceptance tests and executable packaging are subsequently skipped;
this is not a runtime test failure.

The exact source line is:

```cpp
c.width = shape == 0 ? 1920 : 1400; c.height = shape == 0 ? 820 : 1080;
```

The narrow justified correction is:

```cpp
c.width = shape == 0 ? 1920.0F : 1400.0F; c.height = shape == 0 ? 820.0F : 1080.0F;
```

All four values are exactly representable in binary32. This removes the
unnecessary integer conditional conversion while preserving dimensions, case
order, assertions and warning policy. Do not suppress C4244, disable `/WX`,
remove the fixture or alter the matrix to obtain a pass.
