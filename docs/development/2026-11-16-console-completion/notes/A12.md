## Binary protocol for A17

Invocation: `FIXTURE --case INDEX`, with decimal index 0 through 33. The program
writes exactly:

1. One UTF-8 JSON object terminated by one LF, bounded below 2 MiB.
2. Exactly `bytes == width * height * 4` raw bytes: row-major, top to bottom,
   each pixel R,G,B,A, with no pitch padding.
3. End of stdout. There is no trailer, second object, diagnostic or checksum.

Failure produces nonzero exit and a diagnostic on stderr. Windows puts stdout in
binary mode. `--list` needs no SDL initialization. No-argument invocation runs the
ordinary matrix and emits a JSON summary only after all internal checks pass.

Minimal consumer shape (the independent comparator should add strict schema,
source/dependency, case inventory and metadata validation):

```python
completed = subprocess.run([executable, "--case", str(index)], capture_output=True, check=True)
header_bytes, separator, rgba = completed.stdout.partition(b"\n")
assert separator and len(header_bytes) < 2 * 1024 * 1024
header = json.loads(header_bytes)
assert header["protocol"] == "performance-plate-p1-v1"
assert header["case"] == index
assert header["bytes"] == header["width"] * header["height"] * 4
assert len(rgba) == header["bytes"]
```

All numeric geometry is serialized with round-trip precision. The complete model
record includes desired controls, every applied snapshot field, all view fields,
all layout rectangles, all 68 controls, all 147 key records and their hit/top/front
quads. No comparison uses unspecified C++ struct padding. Hit records independently
invoke public hit testing at each control center/corner and key center/vertices.
Renderer records contain both exact scales, physical and logical viewport/clip,
clip enable, blend, and draw color. Backend metadata includes actual SDL version,
software renderer name/flags/formats and surface format. Fixed information strings
and all other `InstrumentViewInfo` values are serialized.

### Witness metadata

`witnesses.full_required` is true for an active, uncut, nonresource frame. Every
such frame requires all 17 text runs, all 19 opaque child probes and nonempty focus
ink. Clipped/resource frames retain the same inventories with honestly empty
intersections allowed. Inactive scenes have no P1 child witnesses and require
complete paired frame equality instead.

All `spans` and `opaque_spans` use `[physical_output_row, first_x, exclusive_end_x]`.
They are sorted, nonempty, disjoint per inventory item and bounded to output.
`pixels`/`opaque_pixels` are their exact sums. Positions include viewport origin.

- `opaque_probes`: four percussion caps, expression track/handle, both pedal
  tracks/caps, divider, four screws, and both rule segments for each heading.
  `logical_regions` are frozen source-derived opaque cores. Their white masks are
  rendered using unchanged Drawing/SDL; no candidate color chooses a sample.
  Each sampled actual pixel must be opaque. The independent paired comparator
  must also require exact before/after RGBA at **every** such sample.
- `text_runs`: both headings, eligibility, four underlabels, four percussion
  values, expression label/value, and two pedal labels/values. Each record gives
  exact literal `text`, centered `box`, requested size, padding, face, RGBA,
  resolved `text_arguments` `[x,top,size]`, source-derived glyph destination
  envelopes, and independently rendered fully opaque glyph core spans. Actual
  RGBA at every opaque core must equal the literal text color exactly. The
  fixture uses the unchanged real font/text path, preserving pinned SDL clipped
  copy behavior; anti-aliased edges are not treated as opaque.
- `focus`: exact semantic ID/bounds, four independently reconstructed logical
  outline rectangles, cyan RGBA `(165,228,223,255)`, and complete expected and
  actual position spans/counts. The actual scan covers the **whole frame**, so an
  extra cyan region cannot hide outside the expected outline.

Text arguments and geometry are source-derived expectations, not an interception
of production calls. Preserve independent source review of unchanged child
