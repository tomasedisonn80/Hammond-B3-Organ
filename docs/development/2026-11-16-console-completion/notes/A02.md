## Console, drawbar and preset requirements

The manual routing layer must retain four different identities: playing key,
electrical tone ID, physical terminal and storage index (p. 97). Its documentary
algorithm uses offsets `[0,19,12,24,31,36,40,43,48]`, a special +12 only for the
lowest twelve keys' 16-foot route, and repeated -12 while a request exceeds tone
91 (pp. 98–99). This preserves all 549 manual routes, including multiple
drawbars selecting the same source at the top key (pp. 100–102). Such collisions
share waveform and phase but keep separate contact and gain histories.

Drawbar positions are connection settings, not measured voltage multipliers.
The atlas's nominal law is explicitly `g(0)=0` and
`g(p)=10^(3*(p-8)/20)` for integer positions 1–8 (p. 111). Same-phase paths add
algebraically; two identical ideal paths double amplitude. A polyphony divisor
would conceal a routing error. The nominal reference must remain independently
available when a loaded network is eventually introduced (pp. 112–114).

Each manual has twelve reversed keys. **C is a momentary Cancel action with no
electrical contacts**; it releases the latch and returns to rest. C#–A select
nine fixed routes; A# and B select the existing left/right banks. Cancel must
not clear held-note ownership, stop the generator, reset phase, disturb the
other manual or change pedals (p. 121). Simultaneous physical latching is a
separate fidelity extension requiring a real branch/loading model; simply adding
two preset output signals is not established by the mechanical observation.

The page-122 Table IV matrix is one documented **chapel arrangement**, not proof
that every B-3 contains those wires. Its 162 digits require independent review
against the primary drawing before a release claims documentary transcription
closure. Store registrations as nine characters to preserve leading zeros.
Tap data, calibrated gains and profile provenance must not be conflated
(pp. 122–123). This reading visually confirms the atlas's displayed table only.

All four manual drawbar banks persist while inactive. Selecting A#/B changes
routing without copying positions. Fixed presets ignore inactive drawbar motion.
The vintage reverse-key action must not also recall expression, Leslie speed,
scanner controls or a generator profile. Modern complete-state snapshots need
explicitly separate scope. Ordinary project restore contains controls and no
phantom held notes; sample-exact replay would require a separate versioned
runtime checkpoint containing histories (pp. 126, 155).

## Percussion requirements and traps

1. **The keying bus is the eighth harmonic/1-foot route, which is the ninth
   drawbar from the left.** It is not the eighth drawbar. Detector contact state
   remains meaningful when its audible drawbar gain is zero (pp. 127–128).
2. Upper B supplies the relevant route. Lower/pedal notes never independently
   enter the upper detector aggregation. Route eligibility, physical contact
   state and envelope/control state need distinct diagnostics (pp. 124, 127).
3. One manual-wide charge/readiness history survives added notes, bank changes
   and held chords. A joining tone enters the existing decaying sound; it does
   not get a fresh envelope. An off/on pair at one timestamp gives zero recharge
   time (pp. 129–132).
4. Multiple input owners may hold one physical key. Removing one owner does not
   release the other. Duplicate events follow a declared bounded policy and
   must not implicitly retrigger percussion (pp. 130, 152).
5. B exit/re-entry, tablet changes and Cancel can change detector connectivity
   while notes remain held. Preserve circuit history and report unmeasured
   switching behavior explicitly. Neither unconditional retrigger nor blanket
   suppression is established as a physical truth (pp. 124, 128, 131–132).
6. The borrowed second/third harmonic has a sustained-return path. Moving that
   drawbar must not directly scale the percussion envelope; returning its signal
   twice is an integration defect. Normal-mode upper attenuation must not
   attenuate the lower division and percussion together (pp. 134–138).
7. Electrical time constants are not audible decay lengths. The atlas derives
   isolated nominal RC products of 1.551 s, approximately 0.375 s and 0.03432 s;
   these do not establish measured V7 gain, actual recharge or envelope cutoff
   (p. 135). A future circuit profile must identify revision, source units,
   transformer behavior and voltage-to-gain assumptions independently.

## Event and state contracts for the next M3/M9 work

Pages 151–156 require one audio-owned applied state shared by VST3, native MIDI,
screen keyboard and replay adapters. A command retains origin and time. A held
note retains its original manual destination when mapping changes, so its later
release cannot be redirected and stranded. Pending UI state must become applied
only after acknowledgement; a copied display snapshot is not another authority.

The atlas proposes discrete routing first at equal offsets, followed by stable
note order and stable contact subevent order (p. 153). This is an explicit
software policy, not a measured statement about sub-sample hardware timing.
Continuous automation must retain its within-block trajectory; an empty queue
preserves the previous value. No callback-count clock, redraw, preset or host
transport event may silently reset source, scanner or percussion state.

All Notes Off, All Sound Off, Reset All Controllers and global Panic are distinct
actions with declared ownership/tail policies (p. 156). A raw-MIDI zero-velocity
NoteOn convention must not automatically be imposed on normalized VST3 events
(p. 152). The proposed future tests should cover held notes across remapping,
inactive bank edits, Cancel then bank selection, equal-time off/on, upper/lower
same-pitch ownership, queue exhaustion and malformed state. Any implementation
must preserve this repository's 47 IDs, `B3CONTROLS4` and readers 1–3, 91 running
sources, UUIDs and nominal dry Engine unless root separately admits a migration.

## Adjacent model findings

- Pedal mapping is independent of the manual map: 200 positions contain 195
  connections and five intentional nulls. The third-contact column duplicates
  the second-harmonic source for pedals 1–7, is absent for 8–12 and uses p+19 for
  13–25. Do not deduplicate the two physical paths or turn null into tone zero
  (pp. 139–144).
- Expression is a common preamp mechanism whose frequency-dependent transfer
  can affect downstream drive. Controller endpoints/inversion and final monitor
  gain are separate. Position motion cannot reset source, percussion or scanner
  history. A simple linear crossfade or gain remains a labeled surrogate until
  loaded capacitance/feedback evidence exists (pp. 145–150).
- Generator artifacts need distinct angular versus pickup-gap routes, shared
  correlations and source/timebase identities; arbitrary global wow or a patent
  forcing rate is not calibrated depth (pp. 85–90).
- Calibration documents separate immutable observations, a versioned fitted or
  nominal profile, a compiled rate-specific bank and advancing state. Reject
  duplicate IDs, nonfinite values and contradictory waveform boundaries; an
  already filtered terminal capture must not receive the same filter again
  (pp. 91–96).
- Scanner graph counts are 18 L, 18 C and 19 output voltages, distinct from 16
  physical plates and nine terminal selections (pp. 157–168). A state-space or
  WDF numerical pass does not close loaded same-Hz or physical capture gates.
