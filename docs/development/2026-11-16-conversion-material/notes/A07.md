## Delivered design

The new contract is **proposed for independent admission**, not yet an accepted
implementation protocol. It fixes exact nearest-even rational conversion,
global command-time collisions, per-key collisions including implicit zero/full
travel, stable original command ordinals and explicit all-command quota counting.
No clamping, nudging, per-block conversion or conversion through an approximate
effective binary64 duration is allowed.

A complete total preorder contains every contact edge, every supplied command,
every positive-duration target arrival and both observation boundaries. Each
record has an occurrence identity. Equal-time group membership and ordering
therefore determine every pairwise order/equality relation without quadratic
all-pairs storage. Before/after command movement signs, repeated-target flags,
final contact bits and final target mappings have separate checks. Muted and
shared-source contacts retain their independent histories.

The version chooses and explains conservative **trajectory-only** budgets before
candidate evaluation: continuous position supremum at most `2^-18` travel, and
edge/arrival time error plus its analytic bound at most `2^-10` host frames.
Exact position comparison uses the union of both piecewise-affine paths' knots;
the endpoint maximum is the continuous supremum because differences are affine
between consecutive union knots. Root bounds use propagated segment anchors,
not a scalar rounding allowance. No audio/filter/physical claim follows.

The document freezes deterministic refusal stages, original 256 KiB input
admission, 4096-bit retained rational limbs, finite segment/edge/arrival/knot
counts, a million counted work units, 32 MiB certificate and 131072-byte native
transport limits. The CLI has a cooperative 30-second deadline; external
qualification has a 60-second timeout. These are offline process limits, not
a callback deadline or allocation-free guarantee.

## Concurrent implementation interface

`tools/contact_grid_conversion.py` owns `ConversionRefusal(code,path,witness)`,
`convert_document(document, *, deadline=None)` and
`encode_certificate(result, *, implementation_sha256, contract_sha256,
deadline=None)`. The numerical result has a fixed nested schema, exact rational
witnesses, canonical binary64 sidecar, paired events/states, full preorder,
continuous-position samples, root bounds and embedded CGGRID1 transport.
The encoder reconstructs the sidecar and reruns bounded conversion before
encoding, so a caller cannot forge an otherwise well-typed nested result.

`tools/convert_contact_grid.py` owns CLI/path preflight, actual file hashes and
single-file temp/flush/fsync/recheck/replace. Success is silent exit 0; refusal is
one bounded JSON line on stdout and exit 2. A refusal does not replace an old
output. This removes a multifile partial-publication problem. N>0 transport uses
one N-frame process block then closure; N=0 is close-only.

An optional distinct install component has an explicit five-file payload: the
four Python modules plus this contract, preserving tools/docs relative layout.
The old 48-file ContactReferenceTools and native module remain unchanged.
