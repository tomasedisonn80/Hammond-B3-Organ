## Independent formulation

The test-only oracle imports no production converter, fractional replay, grid
replay or other numerical oracle. It accepts the unchanged input parser's
canonical immutable `Case` at the test boundary. Exact binary64 values become
Fractions; independently exercised `Fraction.__round__` supplies nearest/even
rounding. It applies the frozen domain/collision and mathematical refusal order.

For each key, it first constructs complete epochs separated by genuine target
changes. No-ops retain the existing anchor. Tied genuine changes replace the
anchor without intervening motion. Moving epochs are clipped at arrivals, with
holding pieces retained. Each of the nine contacts is then scanned separately
over the completed path. This contact-major, completed-path calculation differs
from a merged online event replay. Positive-duration arrivals, inclusive incoming
crossings and command observations have separate records.

Source/grid comparison covers command directions and repetition flags, every
edge and arrival identity/time, complete labeled event preorder, final target and
contact bits, all global-command and per-key path/arrival union knots, continuous
position maxima, persistent root anchors, actual errors and the admitted analytic
root bounds. It keeps all histories for muted and shared-source contacts. The
source-bit sidecar, signed scalar errors, effective-duration relative errors and
CGGRID1 transport are derived independently as well.

Production code is imported only through public `convert_document` and
`encode_certificate` calls in the test class. Accepted comparisons recursively
check both value and Python type, preventing Boolean/integer equality from hiding
schema errors. Expected values never come from production helpers. The candidate
work count is checked as an integer in its contractual range; the oracle uses a
different algorithm, so its operation count is deliberately not an expected
candidate count.
