original binary64 inputs using exact Fraction nearest/even equations, then
compares the candidate grid with that result. A separate literal serializer
reconstructs `CGGRID1`; the actual certificate transport bytes must match and are
submitted directly to the native C++ probe. Strict certificate JSON, all supplied
facts and actual module/contract/Python provenance are checked as well.

independent completed-path/contact-scan grid oracle. Comparisons include exact
mixed rational time, edge order, phase, configuration, counters, every key's
position/target/anchor and all contact bits, including all inactive entries.

against the certificate. Six comparator sensitivity cases prove that changed
anchors, padding, field types, block counts and edge fractions cannot hide.

Use `--report` only with a fresh destination; existing receipts are protected.
The probe is mandatory and missing configuration fails setup. Root should
regenerate CMake to discover this test and run the combined affected converter
gates against the repaired sources before publication.

The probe exposes only final snapshots and per-block counts. Prefix state is
observed in separate processes, and its independent pre-closure oracle comparison
normalizes only phase because the probe always closes. This is not an observation
of an intermediate snapshot inside a longer native process. The accepted corpus
has no exact integer-frame edge; original rejected endpoint cases remain refused,
and the unchanged native differential suite owns that exact-boundary coverage.
The transport exposes no short-buffer retry controls, so the existing native
lifecycle suite remains the separate transaction/rollback gate.

The [native review](../../../reviews/CONTACT_GRID_CONVERSION_NATIVE_REVIEW.md)
details these boundaries. No native build, full CTest, installation, audio render,
commit or push ran here. This is synthetic finite trajectory acceptance; audio,
physical contact calibration, live callback deadlines, indefinite/full-organ
capacity and Engine integration remain unqualified.
