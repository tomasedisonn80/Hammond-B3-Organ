## Delivered API and behavior

The standard-library-only numerical module exports
`ConversionRefusal(code, path, witness)`,
`convert_document(document, *, deadline=None)` and
`encode_certificate(result, *, implementation_sha256, contract_sha256, deadline=None)`.
The refusal preserves its three attributes and falls back to a bounded resource
diagnostic when an exact witness would exceed 8192 bytes. Optional deadlines are
absolute `time.monotonic()` values; booleans, strings, infinity and integers too
large for finite deadline admission are rejected.

The converter revalidates the unchanged original canonical case and metadata,
performs exact Fraction round-to-nearest-even conversion, and retains all caller
commands. Global time collisions, implicit position endpoints and rounded
hysteresis are admitted in the prescribed precedence. Its own replay retains
target-change anchors through no-ops and resets them on every genuine change,
including intermediate tied changes. It records independent contact edges,
positive-duration arrivals, command observations, both boundaries, final bits
and the complete event preorder. Source identity, signed gains and permitted
subnormal binary64 values survive the canonical sidecar.

Continuous position maxima are checked by sweeping both trajectories at union
knots. A13 and independent A15 agreed to include every global source/grid command
time for each key, together with that key's two sets of segment endpoints,
arrivals and 0/N. Shared times count once per key against the 4096-total cap.
Every matched root retains its persistent anchor, threshold, positive speed,
exact actual error and analytic bound.

Scalar paths use original key/contact/caller indices. Key rows contain press
then release speed (`travel/frame`), effective duration (`seconds`), and relative
duration error (`ratio`, original zero and converted absolute relative error).
Contacts use off then on; command time (`frames`) and target (`travel`) rows are
in stable chronological order. All differences are signed grid minus source.
Budget refusal precedence remains edges before arrivals. The certificate's
combined `root_bounds` array is ASCII label order, with arrival labels before
edge labels; its summary witness indexes that output array.

The encoder checks every nested shape and built-in type, all array/string caps,
reduced rational spellings, canonical binary64 encodings and provenance shape
before reconstruction. It reconstructs the sidecar, reruns the bounded converter
under the same deadline and compares every supplied fact with exact typed
equality. This rejects boolean/integer substitutions and forged well-formed
facts. Compact sorted ASCII-safe JSON has one final LF and a 32 MiB byte cap;
CGGRID1 has its independent 131072-byte cap. Original-byte metadata can only be
authenticated by A14's actual file read, not by this pure encoder.
