# Design inputs for independent contract authors

These are proposed implementation choices, not a frozen contract or a passing gate.
Read the existing audio proposal and A50-C1 through C6 review before deciding.

- Keep the C++20 research module separate from Engine. Select N<=256, L256, H16, D16 and existing grid commands/capacities. Outputs are N+33 including both endpoint zeros; N0 is empty. Preserve shared sources with IDs1..91, at most36 configured sources and 4x9 independent signed routes.
- An 8194-cell ring, 8193 coefficients, immutable configuration, per-route exact open starts, one stable cell compensated accumulator and 256 staged samples can have fixed storage. Keep complete committed/staged copies for transactional audio. Memory target <=1MiB per object, to be derived and measured. This is not a callback deadline.
- At ordinary integer callback/frame boundaries do not finalize an open connected interval. Finalize it only on its own contact edge, cell boundary or terminal gate. Maintain canonical event order, then active key/contact order at a cell end; Neumaier compensation can retain cancellation terms without combining route gains. Independently review this numeric policy and limits.
- Exact grid roots are mixed uint32 tick + numerator/denominator. Cells have integer tick boundaries. For differences/midpoints, two uint64 limbs can represent widened products/sums up to roughly89bits without nonstandard __int128. Convert exact width and midpoint only after integer operations, never subtract rounded root displays. Freeze full bounds and degenerate-interval behavior.
- Source phase is explicitly the immutable phase at epoch origin. Ordinary commands/partitions/silence never restart it. A stopped reset starts an independent replay at declared epoch origin, with no cross-epoch continuity claim; a new prepare supplies different source phases. The contract should select and name exact origin/reset semantics instead of keeping an ambiguous optional origin argument.
- CausalContactGrid is noncopyable. A reviewed private friend seam could copy only its committed snapshot into a separately embedded trial grid; execute on the trial; publish its committed state only after audio succeeds. Preserve its public API, validation order and semantics, all existing tests and inactive staging nonobservability. No restore from an unvalidated public caller snapshot.
- Bound waveform arithmetic with finite validated frequency<=0.45F, amplitude0..1, phase[0,1), signed gain[-1,1]. Outward raw bound must remain positive for any nonzero source/route product even when the rounded product underflows. Exact-zero configuration is a separate predicate. Independent oracle should use exact rational bounds and scaled errors.
- Freeze independent exact-grid fixtures and discrete L256 comparisons before candidate errors. Continuous full-window comparison is a separate gate with its own resource budget and original-fixture conversion limits. No old 64-probe result can be presented as that new gate.
- UI work is idle manual keys only in wide reference Play. Keep held/focus cues, pedals, presets, existing drawing API, geometry and other materials unchanged. Other owner is working typography/rim. Prefer bounded gradients/bevels on existing quads, with original source-derived quiet-patch/reference and containment criteria before painter edits.
