## Concrete delivery and decisions

The contract freezes `ContactAudioStream`, `ContactAudioConfig`, named source/
route/origin/result/snapshot types, six lifecycle phases, explicit statuses and
whole-call precedence. The domain is N<=256/L256/D16 with four keys, 36 sources,
512 commands and 4608 edges; standalone grid N<=4096 remains intact. A nonempty
epoch returns all N+33 samples, including both endpoint zeros; N=0 is empty.
A stopped reset replays the same phase values at an exact signed host-frame
**label**, bounded to ±2^48. Origin labels never enter phase arithmetic, and no
cross-epoch continuity claim is made.

A50-C1 is resolved by exact two-limb unsigned rational width/midpoint formation,
nearest-even conversion with bounded remainder division, one canonical Neumaier
accumulator per open cell, preserved per-route starts and explicit cell-before-
edge ties. Independent routes are never combined into a rounded gain. A separate
`ContactAudioTime.h` helper surface also freezes the prepare-only exact outward
raw bound: a 34-limb dyadic accumulator preserves the smallest positive bound
for underflowing route products. Root requested this helper separation so one
worker can implement arithmetic independently of the stream.

A50-C2 is resolved by a narrowly scoped private `ContactAudioStream` friendship:
copy only the committed grid state into an embedded trial grid; execute trial
operations and audio work; commit both only after all numeric work succeeds.
The grid's public noncopyability/API/validation/4096-frame semantics stay intact.
Endpoint physical bits and the raw left limit are retained separately so closure
cannot lose a last break's left-half contribution or make a terminal make audible.

A50-C3/C4 specify state transitions, extra-span behavior, exact result counts,
zero-count calls, output preservation, alias preconditions, origin policy and
stopped reset/prepare boundaries. A50-C5 fixes two complete ring/state copies,
8194 cells/ring, 8193 coefficients, one 4608-edge array, 256 staged samples,
36 pending route starts, <=1 MiB total object and <=16 KiB extra stack. Source
bounds account for the 2304-piece one-cell burst without a piece array and for
frame-interleaved output/eviction, rather than integrating a whole call first.

A50-C6 fixes independent exact-grid/L256 gates (nominal peak/B<=1e-10, eligible
NRMSE<=1e-9), separate cancellation/thin-pulse discrimination, an explicitly
