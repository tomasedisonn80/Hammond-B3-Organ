### 2. Persistent history and full drainage are semantic requirements

Pages 325–328 distinguish a static filter response from its behavior during changing state. For basis filters `g_r` and angular weights `b_r`, page 326 gives different operators:

```text
A: y[n] = sum_r b_r(theta[n]) * (g_r * x)[n]
B: y[n] = sum_r (g_r * (b_r(theta) * x))[n]
```

They agree for frozen angle and can differ during a tail. Moving weights across filtering for convenience changes the system. Page 327 requires continuously running filters and retained input/overlap histories; page 328 explicitly compares variable host blocks with one continuous offline reference, including **final partial partitions and complete tails**. Page 330 describes a historical synthetic 137-input/23-tap example retaining all 159 output samples. That publication's result is not a test of this repository or the future contact implementation.

## Whole-project dependencies and specific pitfalls

1. **Dry before cabinet fitting.** Pages 250–252 keep six scanner modes crossed with Swell/Great routing and separate percussion/pedal inputs. No extra chorus dry mix, no scanner state reset at selector changes, no master-gain fit hiding expression loading.
2. **122 and 147 remain separate.** Pages 253–264 distinguish the June 1971 036616 122 amplifier from 147 and modern 122H. For the 122 boundary, `vd=va-vb`, `vc=(va+vb)/2`, with inverse legs `vc±vd/2` (p. 255). A half-differential convention would introduce a factor-of-two amplitude error. A shared transformer part number does not imply shared winding connections.
3. **Electrical load stays electrical.** Pages 266–276 require transformer/load coupling and preserve the crossover's floating treble terminals. The documentary L2/L3/C16A/C16B values are 3.2 mH / 5.2 mH / 7.8 µF / 12.5 µF; actual losses and driver impedances remain unknown. The nominal 800 Hz/16-ohm description is not an exact cutoff or universal resistor load.
4. **One physical trajectory per rotor.** Pages 279–280 and 301–322 use shared histories with microphone-specific emission times. Distinct paths need not query the same delayed angle. Left/right free-running LFOs, note-triggered phase resets or a GUI-owned rotor clock invent different physics.
5. **Preserve audited source discrepancies.** Page 302 independently expands `r²=R²+a²−2Ra cos(theta)+h²`, noting a sign discrepancy in the cited DAFx equation. Page 303 notes that its printed linear interpolation weights choose the wrong integer endpoint. These are source audits, not manufacturer/author-issued errata. Future code must test endpoints and geometry rather than copy the listings.
6. **No duplicated acoustic mechanisms.** Pages 278, 286, 296–298, 305, 307–310, 316 and 325–332 require explicit ownership for driver, crossover, propagation, cabinet, microphone and room contributions. A complete measured IR cannot automatically receive another instance of the same effect. An appearance asset does not determine the acoustic boundary.
