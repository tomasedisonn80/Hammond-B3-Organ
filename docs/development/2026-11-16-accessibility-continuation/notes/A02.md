## Recommended next bounded product scope

The atlas supports a useful **semantic UI snapshot and action boundary** without
changing contact audio, key/rim painting, scanner, rotary or crossover modules.
The inspected `apps/standalone/UiModel.h` already provides semantic
`UiControlId`, tagged `UiNote`, separate workspace/presentation enums and copied
view state. `InspectionModel.h` provides bounded copied inspection rows with
availability and evidence classes. Build on these identities rather than
introducing parameter IDs or letting an accessibility provider access Engine.

1. Freeze names, roles, values, ranges, selected state, pending/applied state,
   focus and available actions for every currently visible control and
   discoverable playing key. Preserve manual/pedal numeric identities and all
   existing focus behavior. Expose hidden bank values truthfully as retained
   values; do not make hidden controls actionable through a stale tree.
2. Distinguish **EDIT BANK** from **SOUNDING** in both speech and value metadata.
   Use a momentary Cancel action distinct from global Panic. Preset navigation
   alone must not activate a selection or play a note. Expose percussion's
   switch setting separately from upper-B eligibility, and retain unavailable
   model/device states instead of presenting them as zero.
3. Route accessible activation/value changes through the existing main-thread
   request and acknowledgement path. A provider is another input adapter, not
   another sound-state owner. Define momentary note release, modal focus,
   layout changes, stale actions and provider disconnect before enabling key
   audition.
4. Keep expression position/controller calibration distinct from final-output
   metering; keep ordinary Save/Load terminology distinct from runtime replay.
   A copied semantic export could support deterministic implementation review
   now, but it is not itself a native screen-reader bridge.
5. Validate the semantic inventory and action/ownership behavior with independent
   tests, then observe an identified native platform inspector and screen-reader
   journey. Actual OS accessibility, device input, audio deadlines and literal
   whole-interface 1:1 remain separate gates.
