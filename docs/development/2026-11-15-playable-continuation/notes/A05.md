## Implications for the proposed harmonic-source phase

This range supports a prepared harmonic source module, with these boundaries:

1. Declare whether coefficients describe normalized voltage, unloaded pickup
   voltage or a loaded terminal. A voltage-scaled waveform must not receive an
   additional voltage multiplier. Keep pickup differentiation and any embedded
   filter/load effect explicitly owned once (pp.350,357,386).
2. Preserve source IDs 1-91, shared coherent reuse, phase during silence and one
   audio-time owner. A harmonic term does not create an independently seeded
   note oscillator (pp.352,369,379).
3. Perform coefficient validation and preparation outside processing, keep
   histories value-owned or under a verified lifetime protocol, and reject
   unsupported migration while stopped (pp.358,381,388-390).
4. Use declared synthetic coefficients only as a proposed model. Numerical and
   spectral checks can qualify the evaluator; absent pickup captures leave
   specimen calibration open. Never normalize each registration to conceal
   incorrect coherent summation or fit phases per note (pp.364,366,375).
5. Test scalar expected values, bound/rate behavior, silent progression,
   disconnected output, zero-frame boundaries and source-sharing collisions.
   A higher-rate alias reference needs identified reconstruction/decimation and
   convergence; finite all-pass checks are not evidence of audible perfection
   (pp.369-372).
