## Recommended next-phase acceptance

### M2 prepared harmonic sources and explicit offline audition

1. Freeze a separate model/profile identity, source boundary, amplitude units,
   harmonic phase convention and coefficient limits before implementing it.
   Page 459 distinguishes raw pickup, loaded terminal and G–G recordings; page
   489 prohibits applying an already-included pickup/filter response again.
   Synthetic coefficients remain synthetic, regardless of musical plausibility.
2. Preserve one shared phase owner for every source, continuous advancement during
   silence/disconnected processing, deterministic seeds and reused folded sources.
   A note or control edit must not restart an oscillator. Preserve mechanical
   angle versus tooth-phase distinctions when a later physical model adds them.
3. Define supported bandwidth at the actual evaluation rate and a deterministic
   policy for terms at/above the limit. Page 446 explicitly requires anti-alias
   checks before nonlinear source detail. Do not claim that finite harmonics,
   oversampling by name or passing an in-band waveform test proves alias rejection.
4. Accept independent scalar/spectral, fundamental-only reduction, all-source
   identity, rate-change continuity, partition, zero-frame and transactional
   rejection checks. Specify amplitude bounds and confirm no process allocation.
   Compile/load data and build coefficients with processing stopped.
5. First expose an explicit offline audition or separately prepared path with
   model identity in its output report. Keep existing default dry output and
   control/state compatibility as a deliberate regression gate. Later native or
   VST3 selection needs actual adapter and persistence decisions, not an implicit
   switch of the existing model.

This advances useful M2 engineering without assuming a selected specimen or
overlapping the scanner, crossover, MIDI-retirement and R4 implementation owners.
