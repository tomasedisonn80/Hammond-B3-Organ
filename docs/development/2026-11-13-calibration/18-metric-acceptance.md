test's **negative control**, while the exact-rational production comparison
already passed. The test assumed `sum([1e6, 1e-11, -1e6])` would discard the small
term. In the observed Python 3.12 environment, built-in `sum` preserved it, so
asserting inequality with the production result was an invalid test assumption.

the stated naive algorithm. The independent Fraction oracle, its tolerance,
production implementation and frozen contract were not changed. The failure
