## Concrete recommendations for this continuation

### 1. Proceed with the independent M6 numerical phase

The current [next steps](../../../NEXT_STEPS.md), [frozen crossover contract](../../../LESLIE_CROSSOVER_CONTRACT.md) and [characterization](../../../LESLIE_CROSSOVER_CHARACTERIZATION.md) provide a dependency-ready numerical task. Its basis agrees with pp. 178-186 and 245: preserve the circuit, independent oracle and physical boundary while comparing numerical methods.

Before implementing the candidate, independently freeze:

1. Input reconstruction/hold, sample timestamps and external/internal rates.
2. Frequency band and independently selected check grid; all admitted load families and three measured quantities: both signed output ports and input admittance.
3. Separate magnitude/phase criteria above a declared gain floor and absolute complex-error criteria below it, with a separate admittance budget. Document these as engineering decisions; the atlas supplies no audibility threshold.
4. Precharged transient initialization and reference convergence; state-preserving stopped-rate changes; exact failure rollback and valid-call continuation; partition equivalence; energy accounting and bounded storage/runtime work.

Preserve `physical-trapezoidal-leslie-crossover-v1` and documentary L/C values. Evaluate a new realization under a new identity. For example, an exact state transition under a specified piecewise-linear input is a candidate worth deriving offline for the four-state network, but its reconstruction response is not automatically identical to a continuously excited analog circuit. A subdivided/oversampled candidate instead needs explicit reconstruction, output filtering, latency and rate admission. The existing 44.1 kHz model does not admit an undeclared 176.4 kHz internal rate.

Current documentation retains a 44.1 kHz/20 kHz bass difference of about -27.15 dB where analog bass gain is already about -60.23 dB, while the treble magnitude difference is small but its complex error is about 0.05049 V/V. These **previous recorded observations**, not a new experiment by A03, show why neither relative magnitude alone nor one crossover-frequency match is adequate. Keep the existing signed errors and evaluate an entire fixed domain; do not retune components to conceal discretization.
