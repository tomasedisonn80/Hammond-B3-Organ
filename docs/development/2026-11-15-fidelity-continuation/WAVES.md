# Ten-wave execution plan

Six actual agents are dispatched per logical wave, in at most three simultaneous
worker slots beside root. The actual manifest records dispatched identities,
owned files, notes, verification and acceptance. Plans are not worker credit.

| Wave | Six bounded roles |
| --- | --- |
| 1 | Read all 500 atlas pages in six contiguous ranges and inspect the relevant source/figures. |
| 2 | Specify the M6 numerical experiment, visual candidate and native-close study; independently review each contract. |
| 3 | Implement the numerical candidate, visual candidate and close study; add independent reference, behavior and build support. |
| 4 | Qualify numerical lifecycle, UI input/paint, dependency failure and performance/resource behavior; repair concrete defects. |
| 5 | Integrate accepted implementations, retained experiments and practical setup/operation guides. |
| 6 | Capture the actual changed native application, independently review comparison evidence, qualify installation and records. |
| 7 | Review numerical/visual/native contracts against final source, CI requirements and compatibility. |
| 8 | Inspect source-specific hosted platform and sanitizer results; resolve observed failures and preserve original outcomes. |
| 9 | Final source, gallery, workflow and recovery acceptance; reconcile remaining requirements. |
| 10 | Independently verify publication, exact evidence applicability, actual sixty-worker accounting and next-phase handoff. |

Root may refine each bounded assignment based on findings without inventing
completed work or weakening acceptance. Production changes need their affected
coherent checks; photos/nominal models do not establish measured instrument fidelity.
