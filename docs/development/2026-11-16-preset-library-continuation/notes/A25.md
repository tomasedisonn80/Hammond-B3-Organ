## Delivery

Two explicit `EXCLUDE_FROM_ALL` components reuse the existing relative-directory
validator and its already established GNUInstallDirs/DATADIR tracking.
`RegistrationTools` copies the selected native executable to `${BINDIR}` and
the required guide to `${DATADIR}/hammond/REGISTRATION_GUIDE.md`.
`StarterRegistrations` copies exactly 24 named entries plus README/manifest to
`${DATADIR}/hammond/registrations/starter-v1`; metadata stays outside `entries/`.

Each component requires COPY mode or unset/empty, preflights all nonempty inputs
and their readability before writes, rejects symlink inputs/ancestors and
existing or obstructed destinations, and supports staged/relocated paths.
PROGRAMS preserves executable bytes, including with `--strip`; installation
executes no parser, generator, Python or executable and imports no user library.
Both components can share a prefix in either order. Reinstalling either into its
existing destination refuses; it never merges or replaces. Runtime libraries
are not bundled. Copy failure after admission can leave partial new output;
preflight is not a race-free filesystem transaction or automatic rollback.

The nine-method suite authors real private LANGUAGES NONE fixtures, exact file
and directory inventories, complete missing/empty-input admission, directory/
symlink/collision checks, mode/strip checks, custom directories/reconfiguration,
DESTDIR and multi-configuration cases. Copied root install rules are relocated;
all private source/build inputs are removed before native listing, all 24
inspections and scope-aware materializations. The real checkout/build remain
read-only, including their install manifests. Existing OfflineTools tests retain
automatic DATAROOTDIR-tracking coverage.
