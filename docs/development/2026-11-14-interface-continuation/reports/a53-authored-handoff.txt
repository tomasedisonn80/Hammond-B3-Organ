## Reproduce setup, operation and packaging

Commands below are future procedures, checked against source interfaces and
the retained [package qualification](reviews/INTERFACE_FINAL_PACKAGE.md).
A53 performed no build or application execution. Work from the repository root
with C++20, CMake/CTest 3.21+, Python 3.10+, Git, a C compiler and platform
desktop/audio development libraries. Use fresh build/output destinations;
coordinate shared-build ownership first. Windows uses `.exe`; multi-configuration
executables add `Release/`.

Acquire locked SDL 2.32.10 into an absent external directory; an existing checkout
uses `python3 tools/acquire_sdl2.py --verify-existing ../SDL2` instead:

```sh
python3 tools/acquire_sdl2.py --destination ../SDL2
cmake -S . -B build-interface -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON \
  -DHAMMOND_BUILD_STANDALONE=ON -DHAMMOND_SDL2_ROOT="$PWD/../SDL2" \
  -DHAMMOND_ENABLE_MIDI=OFF -DHAMMOND_BUILD_VST3=OFF
cmake --build build-interface --config Release --parallel 2
ctest --test-dir build-interface -C Release -N
ctest --test-dir build-interface -C Release --output-on-failure \
  --no-tests=error -R '^test_standalone_'
```

Discovery supplies the selected revision's inventory. Run affected gates after
changes and the required coherent gate on the fixed candidate; do not repeatedly
run unchanged passing suites. The SDK-free configuration sets
`HAMMOND_BUILD_STANDALONE=OFF`, MIDI OFF and VST3 OFF. The
[preset build guide](PRESET_RUNBOOK.md#build-from-source) supplies its full
commands and optional VST3 acquisition/`check_vst3` procedure.

For MIDI, acquire pinned RtMidi 6.0.0 and configure a separate directory:

```sh
python3 tools/acquire_rtmidi.py --destination ../rtmidi-6.0.0
cmake -S . -B build-interface-midi -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON \
  -DHAMMOND_BUILD_STANDALONE=ON -DHAMMOND_SDL2_ROOT="$PWD/../SDL2" \
  -DHAMMOND_ENABLE_MIDI=ON -DHAMMOND_RTMIDI_ROOT="$PWD/../rtmidi-6.0.0" \
  -DHAMMOND_BUILD_VST3=OFF
cmake --build build-interface-midi --config Release --parallel 2
```
