## Concrete implications for the next M9 slice

1. **Implement real Play, Rotary and Service navigation over one retained state.**
   Pages 412, 415 and 417 require selected/focused states, keyboard navigation,
   per-view focus memory and reliable release through view changes. Switching
   workspace is presentation work: it must emit no sound recall, bank copy,
   phase reset or manufactured release. A captured drawbar gesture closes against
   its original ID before hiding or rebinding (pp399, 412, 416).
2. **Use the present runtime boundary in status language.** The atlas prototype's
   `NO AUDIO` label was accurate for that HTML prototype (pp409, 414-415). This
   repository now plays a nominal dry engine, so copying that label would be
   wrong. The current UI should identify the actual dry output and show scanner
   and rotary integration as unavailable where they are not connected. A cabinet
   picture or locally edited coordinate is not proof of acoustic processing.
3. **Make Service useful immediately from copied values.** Page 413 names six
   subjects: generator; contacts/routing; scanner; AO-28; Leslie; retained control
   state. Expose actual model/profile identifiers, known inventories, sounded
   route versus edited bank, note/control snapshots and explicit implementation
   status. Keep documentary evidence, proposed models, observed executions and
   unmeasured physical fields textually distinct (pp355-360, 367-372). Avoid fake
   waveforms, fake latency, invented voltages, RPM, temperature, specimen IDs or
   authenticity percentages. An AO-28 component list is not a connected circuit.
4. **Keep Rotary honest until its integration contract exists.** Page 413's
   microphone controls are one coherent coordinate system, explicitly not to
   scale; an overview must address the same value, not an independent rig. This
   slice can provide truthful inspection and source context without introducing
   nonfunctional sound controls. Baseline commands are Chorale/Tremolo; the art's
   STOP button conflicts with the text's explicit exclusion of a baseline brake.
   Do not infer an optional brake model from the image.
5. **Refine appearance with dynamic geometry and readable text.** Original page
   409 visibly prioritizes the curved walnut perimeter, shallow panel recesses,
   long adjacent drawbar racks, warm cap highlights, deep manual fronts and a
   large cabinet column. Pages 409 and 411 explicitly preserve correct control
   inventories/labels over mistakes in the generated art. Position 0 is toward
   the upper track edge and 8 extends toward the player. Text, values, focus and
   state indicators must be drawn from semantic live data. A quiet/flat surface
   mode can remove decorative shadows without changing controls (p411).
