## Concrete next M9 Rotary/Service workspace

The dependency-ready interface work is a **read-only, source-backed inspection view** of the actual active instrument and the planned cabinet boundary. It can match the reference's visual navigation and cabinet composition without implying that an unfinished M6/M7 model changes the sound.

1. **Name the active path precisely.** The current instrument's nominal dry output should remain visibly active; scanner, amplifier/crossover, rotary radiation and microphone scene must display their actual unconnected/unavailable state. A reference image or enabled inspection tab must never turn a planned block into an active audio path. Pages 252, 258, 270, 300 and 331 distinguish these boundaries and their evidence.
2. **Keep absent telemetry absent.** Until an owning rotor publishes actual copied state, display unavailable/unknown horn and drum speed, angle, specimen, microphone pose and calibration. Do not use zero RPM or 0 degrees as missing values. When implemented later, show requested command separately from actual model speed; animation follows the latter (pp. 258, 292, 294, 319-322).
3. **Preserve correct physical roles.** Identify the fixed compression driver, single driven rotating horn with counterbalance, fixed woofer and rotating bass deflector. Source concept decoration is not a dimensioned model (pp. 277-278, 283-284, 295, 299-300). Any schematic diagram must label its scale/geometry as illustrative.
4. **Do not quietly add a working Stop mode.** The concept may depict Stop, but the documentary baseline is Slow/Fast. A future brake requires its own identity, semantics and tested state transition; setting a speed display to zero cannot establish it (pp. 256, 289, 294, 319, 323).

View switches, resizing, hiding cabinet art, reduced-motion rendering and editor lifetime must not post sound-control changes, reset notes, change generator/rotor clocks or erase history. UI interpolation must never advance audio state (pp. 292, 318-322, 327-328).
6. **Separate documentary facts from current values.** A source-backed service row can show nominal component identity/value plus units, page locator and evidence class.
