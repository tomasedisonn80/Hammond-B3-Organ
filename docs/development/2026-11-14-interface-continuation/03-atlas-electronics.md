## Exact contracts that an interface must preserve

**Scanner controls and routing (169–174, 250).** The selector changes depth map and electrical return state. At a common depth V/C share the same nine selected nodes: depth 1 is `1,2,3,4,5,6,7,8,9`; depth 2 is `1,2,3,5,7,9,11,12,13`; depth 3 is `1,2,4,7,10,13,16,18,19` (p. 170). These are one-based schematic node labels, not physical lug IDs or array offsets. Chorus's common return is already present in reconstructed chassis-referenced output (p. 171); another decorative dry/wet path would duplicate it. Unconnected controls must not imply this behavior is already audible.

**AO-28 observation boundaries (194–204).** A/B/H designate non-vibrato, vibrato and percussion entries. V3A/V3B are separate sections of one physical 12BH7, not two sockets. Diagnostics should distinguish revision/profile identity, actual observation boundary, electrical scaling and approximations (p. 198). Existing normalized audio must not be displayed as measured volts. Both transformer output legs and their common reference matter; a speculative “output power” value cannot be inferred from valve type.

**Source conflict visibility (235–240).** The factory supply inset identifies C59 where the 1995 redraw repeats C56; preserve both observations, with the accepted factory interpretation and unresolved specimen applicability. The duplicated `6-6-43` inventory callout must not merge electrical instances, and the ambiguous item-47 value remains null (p. 239). Any future service UI should show source/decision/status instead of silently choosing a convenient number.

**State and presentation (172, 184, 226, 234, 244, 249).** Workspace switching, inspection, UI resize and cosmetic changes must preserve sound controls, note owners, shared phase, percussion recharge and transient state. Quality settings may alter only explicitly qualified numerical approximations and latency. A restored profile is a new immutable evidenced configuration, not an age slider. Diagnostic access must consume copied snapshots, with no file access or solver work on the audio callback.
