## Recommended unowned next phase

**First choice: a separate M3 contact-switching numerical reference and
convergence tool**, based on pp. 115-120 and the existing remaining-M3 contract.
This is a useful dependency for later audible contact processing, requires no
invented transformer parameters, and avoids the scanner/library, crossover/MIDI
retirement/deck, harmonic-source/rack and rotary-R4 owners.

Freeze a small versioned contract before coding: explicit source waveform and
phase convention, absolute plus fractional edge times, stable equal-time order,
finite capacities, latency/gain convention, decimator boundary and retained
initial/tail state. A bounded synthetic reference can use declared shared
sinusoidal sources and scripted contact edges without changing Engine or its
ordinary control format. Evaluate source and switching at the high-rate timeline
before low-pass reduction; upsampling an already switched base-rate result is
not an acceptable reference. Preserve the existing nominal sound unchanged.

Required acceptance:

1. Peak and zero-crossing make/break cases cover both value and slope behavior.
2. Shared-source collisions retain distinct contact edges and coherent phase;
   muted paths contribute zero.
3. Fractional and equal-time edges, partial travel, close edge pairs and
   cross-block tails have deterministic retained fixtures.
4. Demonstrate reference convergence before grading a candidate; retain separate
   rate-conversion passband, stopband and latency results. Atlas p. 120's `1e-4`
   normalized RMS threshold is a proposed engineering target, not an automatic
   pass or a manufacturer specification.
5. Partition invariance, sample-rate policy, malformed-input preservation,
   finite bounded state and runtime allocation checks cover the selected API.
6. Report real measured numerical errors and limits. Physical click fidelity
   remains blocked on synchronized key/contact/source/dry-output captures.

**Second choice: an independent stationary loaded-expression research module**
(pp. 145-150), followed by a charge-based moving-capacitance reference. Start with
explicit synthetic parameter fixtures and port/feedback assumptions. Compare
complex transfer at endpoints/interior positions and demonstrate charge/history
continuity before runtime integration. Keep parameter `0x2000` and current scalar
expression semantics unchanged; controller calibration already has another
history and is not this electrical model.

Do not select a production drawbar transformer, pedal reactor or AO-28 gain
curve by guessing missing values. Those can be research topologies with explicit
synthetic fixtures, but cannot become measured default sound without evidence.
