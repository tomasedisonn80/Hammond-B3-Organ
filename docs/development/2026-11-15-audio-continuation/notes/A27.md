## Reproduce

```sh
../build-native/hammond_source_leakage_benchmark --profile ../build-native/nominal.b3p \
  --sample-rate 48000 --blocks 256 --repetitions 5 --seed 739
```

The profile argument must name a regular compiled file of at most 128 KiB. CLI limits are 1–512 blocks, 1–9 repetitions, three supported rates and an unsigned 64-bit decimal seed; each block is 64 frames. Sixteen post-timing CLI checks passed, including help, missing/duplicate/unknown arguments, numeric bounds, absent/directory/FIFO/oversized/invalid profiles. Temporary fixtures were removed.

## Workload and observations

- Nineteen cases: three standalone graph cases plus four Engine configurations × silence/full polyphony × ideal/nominal contacts. Fresh state and the same seed are used for every trial; row order rotates by seven positions each repetition.
- Configurations are unconfigured, empty gain 1, signed two-edge gain 0.75, and signed 728-edge gain 0.5. Core graph timing uses unscaled deterministic dense dyadic frames; exact graph/input recipes are in JSON.
- Each trial warms up 1,024 frames, then measures 16,384 frames. Full polyphony holds 122 manual keys and 25 pedals, both selected B banks at 888888888, both pedal mixtures at 8, expression 0.5 and second/normal/slow percussion enabled. Nominal contacts are checked fully closed after warm-up.
- Timing encloses 64 core calls with status branches or one Engine block call. Preparation, event setup, random input generation and output checksums are outside timing. Clock overhead remains included; a cooperative 50-second work budget is separate from any audio deadline.
- Five repetitions retained all samples, finite/nonzero polyphony, exact silence, frame counts, final source phase and deterministic word checksums. Empty gain 1 matched current unconfigured Engine checksums and phase in all four workloads. These checksums supplement independent numerical correctness tests; they are not cryptographic proofs of equality.
- Total observed work was 1,556,480 measured frames plus 97,280 warm-up frames. One characterization completed in 2.855 seconds internally / 2.862 seconds externally, exit 0, empty stderr; all observed source/artifact hashes remained unchanged.

## Measured medians

GCC 14.2, C++20, Release `-O3 -DNDEBUG`, strict warnings as errors, no sanitizers; Linux x86-64, reported AMD EPYC 9V74, nine available CPUs. Root paused CTest during timing; other host work, affinity, frequency and scheduling were uncontrolled. Load averages and exact compile command are retained.

Core median nanoseconds per frame: empty **137.56**, pair **132.12**, maximum **352.24**. Small rank differences are consistent with timing variation, not evidence of a pair-path speedup.

Retained samples show substantial spread: ideal silent pair ranged 1769–2575 ns/frame. These are bounded shared-host observations, not universal overhead estimates.
