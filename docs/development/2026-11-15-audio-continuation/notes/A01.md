### Preferred additive opportunity: sparse source-domain leakage research

Pages 79–84 give a concrete dependency-ready engineering module. Use the source
frame as input and preserve the diagonal path exactly; compile destination-indexed
sparse gain-only edges outside processing. Each edge has explicit one-based
source/destination, sign/gain convention, pre-contact injection boundary, units,
evidence identity and declared valid range. Use a separate module and explicit
offline experiment first. Do not change the default dry Engine or persisted
control schema without a later reviewed integration contract.

Acceptance should be fixed before implementation:

1. Empty/off-diagonal-disabled graph is exact identity for valid finite input.
2. One edge changes only its named destination, reads the original shared source
   frame, and honors negative polarity; edge ordering cannot introduce feedback
   or recursively apply a previously mixed destination.
3. Independently written dense evaluation agrees within a predeclared numerical
   tolerance. Cover duplicate edges, self-edges, canonical ordering, maximum
   edge count, invalid IDs, NaN/Inf, overflow and input/output aliasing explicitly.
4. Bound output by the row absolute-gain sum stated on p. 81; do not normalize
   away the model's legitimate level changes.
5. Preparation is transactional and outside processing. Processing uses bounded
   storage, no allocation/locks/file I/O, and remains deterministic across block
   partitions. Unknown physical coupling stays unknown.
6. A synthetic fixture labels itself synthetic and does not assert physical
   adjacency from neighboring semitone IDs (p. 80), a measured 91-source matrix,
   default vintage dB level, noise floor or hardware authenticity (p. 84).
7. Pre-contact contamination disappears when its contact route opens; any
   downstream idle feedthrough needs a separate evidence-backed boundary.

Gain-only feedforward work can be tested without hardware data. Filtered edges,
dynamic amount smoothing, prepared graph replacement and Engine insertion each
need their own later contract. A static matrix creates no new frequencies;
coefficient movement can (p. 81).
