## Implications for the proposed M2 leakage phase

The tentative **gain-only sparse source-domain leakage module with explicit offline opt-in** is compatible with these downstream boundaries. It is a useful upstream continuation while R4, crossover, scanner and their current acceptance remain separately owned. This chapter range supplies no measured generator-coupling coefficients and does not promote synthetic values into physical data.

Freeze the following in that module's contract and acceptance:

1. Name the exact source-terminal/input boundary, normalized units and evidence class. Source coupling is not cabinet leakage, microphone crosstalk, mains noise or room crossfeed.
2. Apply every sparse destination contribution to the **same original source frame**, not to already modified destinations. Otherwise traversal order creates unintended cascades/feedback.
3. Preserve signed gains and shared-source phase. Compare against an independent dense matrix for identity, one edge, several edges, cancellation and coherent equal-source cases. Do not normalize by active voices to conceal gain changes.
4. Preserve the generator's free-running phase and note/contact ownership; the new gain layer must not introduce a second oscillator clock. An empty/identity profile must preserve the declared baseline.
5. Compile/validate outside processing; define bounded edge count, finite coefficient limits, alias rules, transactional invalid-input behavior and no callback allocation. Rate independence for static gains is an algebraic property, not a hardware-fidelity claim.
6. Opt-in demonstration renders retain the actual profile/engine identity and synthetic provenance. Their existence does not connect scanner/AO-28/Leslie to Engine or close M2 physical calibration, M5-M8 or product release gates.
7. If a future measured terminal waveform already contains generator coupling, its ownership metadata must prevent this layer from adding the same effect again. The repeated no-double-counting rule on pp.278, 305, 325 and 331 applies directly by analogy.
