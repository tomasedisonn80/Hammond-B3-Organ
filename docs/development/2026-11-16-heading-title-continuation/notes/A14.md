## Delivered

The new CLI requires explicit `--before`, `--after` and a new `--output`
directory. It consumes the genuine 44-case `--list`/`--case` typography
protocol; optional `--before-percussion`/`--after-percussion` add all 66
historical percussion cases. `--build-dir` identifies the coherent build.
The default baseline receipt is this session's `reports/baseline-identity.json`;
the default before painter is beside the retained before binary.

Before invoking either native executable, the tool writes a frozen declaration
of the exact old/new glyph COPY and divider FILL support. It independently
reconstructs old centered text, T2 tracking and rule arithmetic using binary32
rounding, pinned FontData, mapped rack bounds and SDL conversion rules. It
intersects each operation with the output, physical viewport and enabled clip.
There is no dilation, changed-pixel mask or whole-heading allowance. Only
pinned font/float/layout/protocol utilities are reused from the immutable T1
checker; its painter/run/mask declarations are not used.

Every pair requires zero changed pixels outside that support. Inactive,
clipped-away and other empty-support frames require exact RGBA equality.
The 44 typography headers require the expected full model/state metadata and
complete before/after equality. Their 18 canonical cases also require both
warm-ink bounds to meet the frozen reference coordinate, width and improvement
criteria. The reference is measured directly from the pinned JPEG. Optional
percussion headers expose less state; the report explicitly records that limit.

Evidence binds the actual tool, utilities, contract/admission, font, reference,
layout/Drawing/fixture/painter sources, baseline receipt, before/after binaries,
compiler, CMake configuration, static SDL library and pinned SDL COPY/FILL/version
sources. Inputs are rehashed after comparison to reject mid-run changes.
Stdout and stderr are bounded while being read; execution has a timeout.
Raw frames remain in memory only one pair at a time. Failed before/after/outside
PNGs share a configurable 0–64 MiB total budget (32 MiB default); each JSON file
has a fixed 12 MiB maximum. Existing output directories are never overwritten.

  --before ../baseline-native/test_standalone_footage_typography_raster \
  --after ../build-native/apps/standalone/test_standalone_footage_typography_raster \
  --before-percussion ../baseline-native/test_standalone_percussion_raster \

  --build-dir ../build-native \
  --output docs/development/2026-11-16-heading-title-continuation/reports/t2-paired

No native paired pass is claimed here. The historical typography fixture clips
footage labels, not headings; percussion clips likewise miss these headings.
They cover empty/disjoint clipping but **do not cover partial heading glyph/rule
cuts**. The report keeps `full_t2_matrix_complete` false. Root assigned a
separate fixture owner to close that gap. `declare_case` and `compare_pair` are
separate from suite inventory and CLI dispatch so a later pinned clips protocol
can add `--before-clips`/`--after-clips` without changing historical masks.
T3 and whole-interface 1:1 remain separate work.
