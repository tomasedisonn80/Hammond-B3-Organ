## Implemented contract

The standard-library checker locates this session relative to its own file,
reads records without modifying them, and writes one JSON summary to stdout.
Default mode validates actual incomplete progress. `--strict` additionally
requires all A01-A60 accepted with ten complete six-worker waves.

Validation rejects duplicate JSON members, nonfinite constants, unexpected or
missing schema keys, incorrect fixed session/base/request counts, duplicate or
out-of-range worker IDs, duplicate/wrong agent identities, incorrect waves,
empty tasks/ownership and unsafe relative ownership paths. Each accepted row
requires a chronological timezone-aware acceptance record, root review, its
assigned note path and exact SHA-256. Notes must be regular UTF-8 files within
the session, at least 301 bytes and no more than 2 MiB. Size is only a basic
substantiveness guard, not an assessment of content quality.

The atlas receipt must name the unchanged PDF, all six accepted readers and
their exact ranges, covering pages 1-500 without gaps or overlap. The checker
rehashes the actual PDF and all six notes, then cross-checks note identities
against the worker ledger. Extract digests are format-checked; transient text
extracts outside the repository are not required in a later checkout.
