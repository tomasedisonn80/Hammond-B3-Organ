## Delivered source and protocol

The supplemental fixture provides **48 fixed cases** under schema 1 and protocol
`typography-clips-v1`. `--list` emits `cases` plus `inventory`; `--case INDEX`
emits one bounded JSON line followed immediately by exactly `width*height*4`
RGBA bytes. The generic `compare_footage_typography.py` frame parser accepts this
wire shape; actual executable parsing remains unrun by this worker.

Indices 0–15 use scale 1 with physical caller clips: Upper, Lower and title each
receive left/right/top/bottom cuts, followed by separate cuts through all four
side rules. Indices 16–31 repeat those windows as logical clips at scale 1.25.
Indices 32–37 cover enabled zero-width, zero-height and both-zero clips at both
scales; 38–39 are disjoint from the viewport. Indices 40–45 are Flat, Rotary,
Service, 960×700, immediately below width 1400 and immediately below height 820.
Indices 46–47 are unclipped canonical/1.25 frames. Origins alternate positive
and negative, except the canonical zero-origin case. Outputs are checked before
allocation against 2160×1240; no maximum-size full frame is allocated.

Every case declares A/B/fixed-D/Cancel routing, drawbar level, held notes,
pending controls, edited bank, focus, workspace, presentation and blend mode.
Headers include those declarations, logical/output dimensions, actual queried
physical and logical viewport/clip, scale, enable state, complete padding-free
model records and assertion indicators. The existing explicit serializer was
copied byte-for-byte without altering its historical source.

Default and streamed cases assert transform/blend, model and session
preservation, finite bounded clips, exact containment outside the caller window
after SDL's whole-target clear, and deterministic repaint. Default execution
also checks repaint after another state and on a fresh renderer. No candidate
heading/title strings, typography equations, font oracle or edit allowance is
included. Clipped text is not compared to an uncut resampling.
