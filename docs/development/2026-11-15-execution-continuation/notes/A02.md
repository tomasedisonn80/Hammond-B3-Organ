identifiable correlation. Profiles distinguish observations, proposed/fitted
parameters and compiled runtime data; a post-filter waveform must not receive

not measured transformer loading. A loaded model must retain individual branches,

clearing keys; simultaneous preset latches cannot be approximated as independent
program sums without a separately admitted model.

**Pages 127–150:** percussion uses one upper-B detector and continuous history;
contact 8 means the ninth/1-foot contact. Drawbar mute does not erase keying.
Preset/tablet transitions preserve charge history. Pedals share the generator,
retain all eight contact positions/four buses, and require a separate loaded
network. Expression changes loaded frequency response and downstream drive;
controller calibration and final monitoring gain are separate responsibilities.

## Current gap and next implementation

The current console already preserves 1,098 independent manual contacts,
hysteresis, partial targets and shared source coherence. `ContactBank::advance_frame()`
updates binary contacts after whole-frame travel. `Engine::process()` renders
current coefficients, then advances contact/readiness state; coefficient
aggregation occurs only after individual contacts are evaluated. The design is
consistent with its declared nominal contract.

The dependency-ready gap is **M3 fractional contact switching and numerical
bandwidth characterization**. `CONSOLE_DYNAMICS.md` explicitly excludes fractional
edges and band-limited switching; `M3_REMAINING_AND_SCANNER_GATE.md` already names
the required reference/convergence experiment. Existing contact-rate tests verify
sample-grid threshold timing and lifecycle, not switched-audio alias control.
The audio session's moving-contact/leakage composition also tests the existing
model and does not close this gap.

Recommended bounded implementation:

1. Freeze a separately identified contact-edge contract with absolute frame plus
   fraction, stable equal-time ordering, bounded capacity, overflow response,
   exact endpoint normalization and separate make/break events. Derive crossings
   from full travel velocity; interpolating across a target-clamped frame can
   give an incorrect edge time. Preserve existing contact/model identities.
2. Build an independent offline switched-source reference using explicit nominal
   source frequencies/phases and analytic trajectories. Evaluate sources and
   switching before filtering/downsampling. Use a declared filter, latency and
   gain convention; do not upsample an already switched base-rate Engine render.
3. Publish convergence and comparison reports at 44.1/48/96 kHz covering source
   peaks, zero crossings, folded-source collisions, partial holds, release/repress,
   simultaneous edges and block-boundary tails. Predeclare a tighter reference
   convergence budget and bounded experiment cost before grading a candidate.
   Atlas p.120's normalized RMS `<=1e-4` is a proposed engineering target,
   not an already satisfied or manufacturer criterion. Report value/slope errors,
   spectral residuals, latency, resource use and failures separately.

This can proceed without scanner/library, harmonics/leakage, crossover, R4 or
MIDI-retirement changes. Retain the nominal dry Engine, all 47 parameter identities
and `B3CONTROLS4`/readers 1–3. Live audio integration follows independent admission;
hardware contact fidelity still requires synchronized gesture/contact/phase/dry
captures. Loaded drawbar, expression and pedal models remain valuable subsequent
work, with missing impedances/topology/capacitances explicitly unresolved.
