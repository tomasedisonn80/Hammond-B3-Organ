## Implemented boundary

Strict UTF-8 JSON admits at most 262,144 bytes and twelve container levels,
rejects duplicate/unknown/missing members, invalid types/booleans, nonfinite
numbers, identifiers and all kernel-domain violations. Input order is retained
in immutable tuples. All three CLI options are required; abbreviations,
duplicates and unsupported factors fail with bounded stderr and empty stdout.

Regular-file and existing-parent preflight rejects inode aliases, including
hardlinks/resolved symlinks, special files and missing parents. Input symlinks
are supported; output leaf symlinks are explicitly unsupported because replacing
the link versus its target would be ambiguous. Trailing directory spelling is
rejected. Read identities and destination/parent identities are checked again
before writing and replacing. The complete finite report is encoded before a
same-directory temporary file is opened; flush/fsync precede atomic replacement.
Owned temporary files are removed on tested failures, preserving prior bytes.

Reports have exactly the frozen root keys, input-byte SHA-256 and all three
implementation hashes. Targets retain stable processing order and zero-based
input ordinals. Edges retain rational numerator/denominator decimal strings,
normalized display coordinates, signed jumps and the exact observation flag.
The terminal gate uses the negative ungated left limit, excluding physical
crossings at N from the audible interval. Empty renders retain final no-time
targets, zero counts/offset/output bound and null filter metadata.

Observations distinguish declared grid/work bounds from measurements, identify
the outward-bound rounding allowance, ideal output bound and acausal timeline,
and record serialized report bytes. Elapsed time excludes final serialization
and replacement. Linux/macOS RSS uses documented `ru_maxrss` units; unavailable
platform measurements are null with reasons and resource-ineligible status.
An individual report never qualifies complete-suite resources or an oracle.
