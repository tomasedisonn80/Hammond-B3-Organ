## Constraints for the imminent pedal work

1. **Keep the source boundary unchanged.** Page 464 reiterates one running phase
   per physical source. A folded or repeated branch does not create an oscillator.
   The pedal map's 200 positions, 195 connections and five disconnections are
   explicit. Preserve contact states and branch identity before mixing.
2. **Separate retained controls from playing history.** Page 440 explicitly
   describes 36 manual values plus two pedal values. Cancel preserves held key
   ownership, other-manual state and pedal settings. Pages 450/468 distinguish
   ordinary preset serialization from an exact DSP checkpoint. Migrations must
   retain this separation rather than restore owners/phases/readiness accidentally.
3. **Make the surrogate replaceable.** Page 447 allows useful console work behind
   a named organ-circuit boundary before complete AO-28 connectivity. A new pedal
   transfer should declare dimensionless normalization, parameter limits and
   omitted reactor/loading behavior, while retaining observable event semantics
   for later physical replacement.
4. **Preserve transaction and clock semantics.** Pages 446/453/468 require stable
   same-frame order, half-open blocks and non-advancing zero-frame controls. All
   preparation, parsing, allocation and destruction remain outside processing.
   Rejection and mid-render failure are different outcomes; the selected bounded
   linear kernel can and should reject before mutation.
5. **Do not equate typed input with a native host.** Pages 434/438/442 require
   original press ownership across focus/bank changes, separate UI and external
   owners, original gesture identities and actual platform dispatch evidence.
   The current typed adapters can support future integration without claiming
   MIDI byte decoding, VST3 export or device operation that has not been built.
6. **Keep diagnostic units and provenance explicit.** Pages 423/425/489 require
   port identity, units, timebase and exact model/profile. An independently checked
   normalized bus or WAV is computed engineering evidence; adding it to a plot or
   export cannot make it a measured instrument observation.
