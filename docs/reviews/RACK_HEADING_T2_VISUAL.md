original reference and from each of the three baseline/T2 size pairs. I

The crops make the intended tracking change particularly clear. The canonical
T2 runs approach the source run lengths while retaining complete letter forms
and separated word spaces. The minimum-active crops confirm that thin serif
strokes remain readable; the wide crops show consistent spacing and level
letters. No crop shows a cut initial/final letter, broken word, letter/rule
contact or contact with a rack edge. They also expose the residual honestly:
the reference letters and rules are brighter and heavier, while the T2 live
glyphs and rules remain fine and flatter.

## Independent fixed-region observations

I decoded the original JPEG and genuine baseline/T2 canonical PNGs to RGB and
read exactly the contract's text-only regions: Upper `(210,278,300,25)` and
Lower `(720,278,308,25)`, expressed as `xywh`. The predicate was unchanged:
`R >= G >= B` and `2126*R + 7152*G + 722*B >= 1600000`. No regions or
thresholds were selected from the candidate difference. Bounds below are
half-open `xyxy`; this operation read pixels without modifying images.

| Heading | Reference bounds / count | Genuine baseline bounds / count | T2 bounds / count |
| --- | --- | --- | --- |
| Upper | `(223,285,496,297)` / 726 | `(214,284,457,296)` / 561 | `(223,285,496,297)` / 560 |
| Lower | `(734,285,1017,297)` / 734 | `(733,284,981,296)` / 581 | `(733,285,1016,297)` / 577 |

Upper's sum of absolute bound errors improves **50 → 0**, and Lower's improves
**39 → 2**. Maximum individual bound error is respectively 0 and 1 pixel.
Widths improve from 243 → 273 pixels and 248 → 283 pixels; both candidate
widths equal the corresponding reference width. Thus these independently read
gallery pixels satisfy the frozen canonical placement criteria. They do not
establish glyph-shape equality, containment or a density gate.

At the unchanged row 292, using strict `R > G > B`, the contract's 750000
weighted threshold and four fixed rule windows, source spans are
`[140,205)`, `[513,564)`, `[662,715)`, `[1035,1083)`; T2 spans are
`[140,206)`, `[514,564)`, `[662,716)`, `[1034,1082)`. These small endpoint
differences remain visible evidence of a live raster treatment, not exact source
rule pixels. All observed rules remain clear of the glyph ink.

The candidate's lower warm-ink counts and fine strokes also remain: T2 is
lighter and more uniform than the reference lettering. No new acceptance
threshold is inferred from density. The original
[110-pair report](../development/2026-11-16-heading-title-continuation/reports/t2-paired/report.json)
has 110 individually passed results but overall status **failed**, because

`6117a0da8a3d0a9c292653e6cc838b7ac911113227007a2e263989b20fcd883c`.
I retain that invalidation and do not use it as final containment acceptance.
