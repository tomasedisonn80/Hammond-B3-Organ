# Standalone font assets

The optional native instrument uses the committed
[`FontData.h`](../apps/standalone/FontData.h) for dynamic labels. It contains
individual antialiased glyphs, not precomposed words. Neither the executable nor
the ordinary C++ build needs Pillow, SDL_ttf, FreeType or a runtime font file.

## Sources and rights

Unmodified **DejaVu Sans Book 2.37** and **DejaVu Serif Book 2.37** are retained in
[`assets/standalone/fonts`](../assets/standalone/fonts/). They were copied from
the local `/usr/share/fonts/truetype/dejavu` directory without downloading fonts.
The [source manifest](../assets/standalone/fonts/source-manifest.json) records
their byte counts, SHA-256 hashes, source locations and rasterizer identity.
The installed distribution package version was unavailable; the font's own
name table identifies version 2.37.

The complete [font notice](../assets/standalone/fonts/LICENSE-DejaVu.txt) is
retained from the `Files: *` section of the local
`/usr/share/doc/fonts-dejavu-core/copyright` and copied into the generated header.
It contains the Bitstream copyright/trademark and permission terms; DejaVu
changes are public domain. That file's separate GPL-2+ Debian packaging section
is **not** the license of these font files. Distributions containing the atlas
or source fonts must retain the complete font notice with their notices; source
comments alone do not supply an installed application's accompanying notice.
This font record does not settle unrelated application or research-asset rights.

## Deterministic authoring

From the repository root, use **Pillow 13.0.0 with FreeType 2.14.3**. The
[authoring requirement](../assets/standalone/fonts/requirements-authoring.txt)
pins Pillow; the generator also verifies the actual FreeType version, both
source-font hashes and the license hash before writing anything.

```sh
python3 tools/generate_standalone_font.py
python3 tools/generate_standalone_font.py --check
```

`--check` regenerates in memory and compares both generated files byte for byte.
Every run checks alpha decoding, all 190 glyph rectangles/advances, nonoverlap,
transparent gutters, baseline bounds and intermediate antialias coverage.
There are no timestamps or absolute build paths in generated output. Intentional
toolchain changes require reviewing the manifest and regenerated bytes. These
are authoring commands, not automatic build/configuration steps.

| Atlas | Nominal size | Dimensions | Alpha bytes | RLE bytes |
| --- | ---: | ---: | ---: | ---: |
| Sans | 32 px | 512 x 256 | 131,072 | 28,168 |
| Serif | 40 px | 512 x 256 | 131,072 | 36,894 |

The generated header is 204,816 bytes. The
[atlas manifest](../assets/standalone/fonts/atlas-manifest.json) records its
SHA-256 and each decoded/encoded alpha hash. Packing uses ASCII-order shelves
with two transparent pixels around each glyph and power-of-two atlas height.

## C++20 drawing API

All declarations live in `hammond::standalone::font_data`:

- `kSans` and `kSerif` are immutable `Atlas` values. Fields are `width`, `height`,
  `pixel_height`, positive `ascent`/`descent`, `glyphs`, `alpha_rle` and
  `alpha_rle_size`. `glyphs` is a fixed-extent span of 95 `Glyph` records.
- `glyph(atlas, unsigned char)` addresses printable ASCII 32..126. Other bytes
  return `?`; space has zero bitmap area and a positive advance. Callers own line
  breaks. Unicode shaping, kerning and localized glyph coverage are not supplied.
- `Glyph` exposes `x`, `y`, `width`, `height`, signed `bearing_x`/`bearing_y` and
  `advance_64` in 1/64 nominal pixels. The source rectangle excludes padding.
- `decode_alpha(atlas, destination)` returns `bool`. The destination must be
  exactly `width * height` bytes. RLE is consecutive unsigned `{count, alpha}`
  byte pairs, count 1..255, traversing rows from top left. Malformed streams fail;
  the destination may be partially written on failure.

On the main thread at startup, decode once and create a texture with RGB 255
everywhere, including transparent pixels, and the decoded alpha. Use alpha
blending, linear filtering and texture color modulation. For requested size `s`,
let `scale = s / atlas.pixel_height`; at pen position `x` and baseline `b`, draw
at `(x + bearing_x * scale, b + bearing_y * scale)` with dimensions
`(width * scale, height * scale)`, then advance by `advance_64 * scale / 64`.
For a top-aligned line, `b = top + ascent * scale`. Texture construction and
drawing remain outside the audio callback. Actual window legibility and DPI
acceptance belong to the renderer's executed screenshot checks.
